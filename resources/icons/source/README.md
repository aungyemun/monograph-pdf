# Branding artwork

| File | Role |
| :--- | :--- |
| `Monograph_PDF_logo.png` | **Canonical artwork** (emblem + wordmark). Import updates with `scripts/prepare_logo.py`. Never edit derived files by hand. |
| `monograph_pdf_icon_1024.png` | Square emblem only — generated by `scripts/generate_branding_icons.py` |
| `monograph_pdf_logo_512.png` | Full logo for About / README — generated by the same script |

Windows sizes and `../windows/monograph_pdf.ico` are also generated. After replacing the canonical PNG, run:

```text
env\Scripts\python.exe scripts\generate_branding_icons.py
env\Scripts\python.exe scripts\generate_branding_icons.py --check
```

Legacy names (`PDF_logo.png`, `pdf_editor*.ico`) must not appear here.
