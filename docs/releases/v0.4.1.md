Monograph PDF 0.4.1, released 2026-10-23. A bug-fix release of the offline PDF editor for Windows 10/11 (64-bit) that also switches on **signed update checks**: a crash when choosing a font, Japanese and other fonts installed as font collections (.ttc) now embedded, and a simpler Compress PDF dialog. Update checks contact GitHub only when you ask (automatic checks are optional and off by default) and install nothing without your confirmation. The sending of problem reports remains switched off.

## Security updates

- **Update checks are switched on.** **Help ▸ Check for Updates…** contacts only this project's GitHub Releases page, accepts only update information signed with the Monograph PDF update-signing key (Ed25519, key id `27c3b3b23b949c40`), and downloads or installs nothing until you click **Update Now**; the downloaded installer must match the SHA-256 in the signed information before it is run. Automatic checks are optional and off by default. Signed update information is valid for at most 730 days; expiry never affects using the program.
- When a check or an update fails, the message names the situation (for example no internet connection, invalid digital signature, expired update information, installer integrity check failed), says that nothing was downloaded or installed, and offers **Open Releases Page**.
- **0.4.0 and earlier cannot update themselves.** Install 0.4.1 once with Setup from this page; later versions can then be found with **Check for Updates**.
- Monograph PDF and its helper programs never open a console window (checked by tests).

## Defects corrected

- **Crash when choosing a font while editing text**: picking a font in the **Properties** panel after selecting typed text could close Monograph PDF without a message.
- The font list in the text toolbar closed on the first click instead of opening, and turning the mouse wheel over a font box changed the font of the selected text.
- **Fonts installed as collections (.ttc / .otc)**, for example MS Mincho, MS Gothic, Meiryo, Yu Gothic, SimSun or Cambria, were replaced by a built-in font ("font collections (.ttc) are not embedded"). The chosen face is now embedded (only the characters used) after checking its embedding permission. Japanese text in MS Mincho and MS Gothic keeps full-width spacing after saving instead of overlapping.
- Settings survive direct upgrades over several versions; a setting of the wrong type no longer silently replaces your value later; an unreadable settings file is copied aside instead of being overwritten; settings and the recent-files list are saved safely.

## Improvements

- **Compress PDF** asks one question with five explained answers: **Best quality (lossless)**, **Balanced (recommended)**, **Smallest file**, **Fit a size limit** and **My own picture settings**. It states what is always kept unchanged (text, fonts, comments, form fields, drawings, links, bookmarks, page layout) and fits a 1366 × 768 screen.
- **Problem reports after a crash** say what happened (kind of fault, the place in Monograph PDF's own code, the last few actions). They are shown in full and still not sent anywhere.

Full list: [CHANGELOG.md](https://github.com/aungyemun/monograph-pdf/blob/v0.4.1/CHANGELOG.md).

## Compatibility

- Windows 10/11, 64-bit. Setup upgrades an existing 0.4.0, 0.3.0 or 0.2.x installation in place and is designed to keep settings and documents.
- Files created with earlier versions open and save as before.

## Known limitations

- Windows 10/11 64-bit only; the installer and program are not code-signed.
- Updating from 0.4.0 or earlier requires installing 0.4.1 with Setup once.
- The sending of problem reports is switched off; a problem report can be copied and posted on the issues page by hand.
- Signatures are visual only (not certificate-based digital signatures).
- Monograph PDF shows one document at a time; opening a second PDF replaces the first (it asks about unsaved changes).
