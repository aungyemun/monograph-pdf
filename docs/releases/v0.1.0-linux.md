# Monograph PDF 0.1.0 (Linux)

First **Linux** release. Versioning is independent of the Windows product line
(Windows remains at 0.5.0).

**Unsigned.** This release ships without code signing or a signed update manifest.
Signing will follow in a later Linux release. Prefer the official GitHub source /
release archives only.

## Download

Linux 0.1.0 is distributed as source from the `linux` branch / this tag:

* Run from source: see [LINUX.md](../../LINUX.md)
* Optional per-user install: `installer/linux/install.sh`

Published Windows installers (`MonographPDF_*_Setup.exe`) are a separate line and
are not part of this Linux 0.1.0 tag.

| File | Role |
| :--- | :--- |
| `MonographPDF_0.1.0_Source.zip` | Corresponding source (when published) |
| `MonographPDF_0.1.0_Installer.zip` | Linux install bundle (when published) |

## Verification

When release archives are published, verify SHA-256 against `SHA256SUMS.txt` in the
release. Until then, build and test only from this repository tree on a trusted machine.

```text
# placeholder until the first published Linux archives exist
# <sha256>  MonographPDF_0.1.0_Installer.zip
# <sha256>  MonographPDF_0.1.0_Source.zip
```

```bash
sha256sum -c SHA256SUMS.txt
```

## Known limitations

* Automatic update install for Linux packages is not published yet (Help ▸ Check for Updates
  remains available for signed manifests when a Linux channel exists).
* Microsoft Office COM conversion is Windows-only; use LibreOffice on Linux.
* Certificate-based digital signatures are not supported (visual signatures only), same as Windows.
* OCR uses a system or micromamba Tesseract binary linked under `engines/ocr`, with pinned
  tessdata_fast eng/jpn/osd — not the Windows DLL set.
