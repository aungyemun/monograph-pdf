Monograph PDF 0.4.0, released 2026-10-23. A feature and reliability release of the offline PDF editor for Windows 10/11 (64-bit): fixes for problems found in daily use of 0.3.0, a security fix for PDFs protected with a permissions password, editing of placed stamps and signatures, exact page positions, one window at a time, and low memory use while minimized. Update checks, automatic upgrades and the sending of problem reports remain **switched off**.

## Security updates

- A PDF protected only with a permissions (owner) password — it opens without a password but forbids, for example, copying or changing — **lost its owner password and all its restrictions when saved** in 0.3.0 and earlier: an unprotected file was written. Saving now keeps the protection exactly as it was. **Document Properties** and **Protect ▸ View Permissions** showed such files as "not encrypted, every action allowed"; they now show the real restrictions.

## Defects corrected

- A crash in the font list (an error while drawing a list row closed the program); the list now opens with one click and scrolls evenly.
- Slow dragging of text boxes and pictures on large forms; highlights and comments flashing the page; Undo / Redo of comments not updating the page.
- The eraser needed several passes; sticky notes could not be opened; a field or text box just added could not be typed into by double-clicking.
- Pictures and boxes could be pushed half off the page (also after rotating pages).
- Stuttering and high memory use when zooming in on scanned pages (400 %: 835 → 131 ms; slowest scroll step 144 → 33 ms).
- Number boxes too narrow for their values; User Guide contents links; plain-language permissions; problem-report dialog in a build without a reporting service.

## Improvements

- **Edit Stamp** (double-click a stamp): type, text, font, colors, border, corners, thickness, opacity, rotation. Placed signatures can be edited the same way.
- **Insert Blank Pages… / Insert Pages from PDF… / Move Pages…** at an exact position (before or after page N, beginning, end).
- Select several fields and text boxes (drag a rectangle or Ctrl+click) and change their font, size and color at once; shape line and fill colors.
- Two-sided printing (long edge by default), Actual size and All pages as defaults.
- **Compress PDF ▸ Custom** (picture resolution and JPEG quality).
- Larger, zoomable page-design previews with **Larger Preview…**.
- **One window at a time**: starting Monograph PDF again opens the file in the running window.
- **Memory saving while minimized**: about 30 MB in the background; Windows efficiency mode unless a job is running.

Full list: [CHANGELOG.md](https://github.com/aungyemun/monograph-pdf/blob/v0.4.0/CHANGELOG.md).

## Compatibility

- Windows 10/11, 64-bit. Setup upgrades an existing 0.3.0 or 0.2.x installation in place and is designed to keep settings and documents. **The upgrade and the preservation of settings were not tested for this release** (the installer test was not run; see Verification).
- Files created with 0.3.0 and 0.2.x open and save as before; stamps made with 0.3.0 keep their exact look.

## Verification for this release

- Automated tests in the release build (Windows 11, commit `fc411e2`): 1633 passed, 0 failed, 5 skipped. The skipped tests need Microsoft Office or LibreOffice for some round trips, or a local test build.
- GitHub Actions on the release commit ([run 39899510936](https://github.com/aungyemun/monograph-pdf/actions/runs/39899510936), Windows Server 2022): 1587 tests passed, none failed, 14 skipped because Microsoft Office or LibreOffice, two Japanese system fonts, private PDFs or a local test build are not present on the runner.
- Installer test (fresh install, first launch, upgrade, settings and document preservation, uninstall, reinstall, shortcuts and uninstall registration): **NOT RUN** for this release (maintainer decision; no isolated Windows test environment was available, and the test is never run on the maintainer's own Windows account) — 0 passed, 0 failed. The upgrade from 0.3.0 / 0.2.x and the preservation of settings were therefore not tested for this release.
- Installer checks without installing: the release build's contents check (every one of the 500 installed files against the tested program folder), the program's self-check (including no network use), the uninstaller and update-helper self-checks, the version information of every program file (0.4.0) and the Setup inside the Installer ZIP all passed. The single-instance handover and memory-saving mode were also checked with the built program.
- Release set (file names, checksums, `SHA256SUMS.txt`, ZIP entry names, notices, versions, privacy scan, OCR components, update-trust configuration, provenance, SBOM): passed in the release build (`verify_release.py`, `RESULT: PASS`).
- Performance (scripts/perf_check.py, 1400 × 900 window): peak memory 353 MB for a 300-page and a 40-page scanned document; no scroll or zoom step over 100 ms; about 30 MB while minimized (built program: 240 → 28 MB).
- **NOT VERIFIED**: installation on a clean Windows PC; Windows 10; non-English Windows; an administrator-run all-users installation; a PC with 8 GB RAM (memory use was measured on the development PC); printing on a physical printer in this release.

## Known limitations

- Windows 10/11 64-bit only; the installer and program are not code-signed.
- Update checks, automatic upgrades and the sending of problem reports are switched off; install new versions from the Releases page. A problem report can be copied and posted on the issues page by hand.
- Signatures are visual only (not certificate-based digital signatures).
- Monograph PDF shows one document at a time; opening a second PDF replaces the first (it asks about unsaved changes).
