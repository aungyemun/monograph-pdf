Monograph PDF 0.2.3, released 2026-10-21. A reliability and security update of the offline PDF editor for Windows 10/11 (64-bit); no new features; everything else works as in 0.2.2 apart from the corrections below.

## Security updates

- **Remove Hidden Information** now also finds and removes open actions that open a web address, launch a program or submit a form (only JavaScript open actions were removed before), document and page automatic actions, and JavaScript in bookmarks. Bookmarks, web-link bookmarks and "open at page" actions are kept.
- New byte-level tests check that password-protected copies contain nothing readable without the password, use the chosen encryption (AES-256 or AES-128) and permissions, and carry no earlier revisions of the document; and that Remove Hidden Information leaves no earlier revisions, page or image metadata, XFA form data or bookmark scripts behind.
- The limits of Remove Hidden Information are now documented: content on the pages themselves (including text in pictures and layers that are turned off) is not removed. See [Security and Privacy](https://github.com/aungyemun/monograph-pdf/blob/v0.2.3/docs/SECURITY_AND_PRIVACY.md#hidden-information).

## Defects corrected

- The first published 0.2.2 release notes showed template placeholders instead of the checksums and results; corrected notes are in the repository (`docs/releases/v0.2.2.md`). The 0.2.2 files were not changed.
- `Installer.zip` entries used `\` separators, which some unzip tools turn into odd file names; they now use standard `/` names.
- Navigation panel: tabs no longer hide behind scroll arrows; the scroll buttons were drawn as white boxes in the dark theme.
- `scripts\run_tests.ps1` stopped the whole test run when a test wrote to standard error; tests on a fresh checkout failed because generated sample files were created too late.

## Improvements

- Every release is now checked before publishing: release notes (no unresolved template values, checksums match the files, results present, links valid) and the complete release set (file names, checksums, ZIP entry names, notices, versions, privacy scan).
- Automated tests run on GitHub Actions (Windows) for every change, including OCR with an engine used only when every file is identical to the one shipped.
- Test results are reported per category (PASS, FAIL or NOT VERIFIED), so skipped tests are never counted as passed.
- README, documentation and screenshots updated; new release checklist and code-signing documents.

Full list: [CHANGELOG.md](https://github.com/aungyemun/monograph-pdf/blob/v0.2.3/CHANGELOG.md).

## Compatibility

- Windows 10/11, 64-bit. Upgrading keeps settings and documents; the upgrade from 0.2.2 was tested for a per-user installation (the per-machine upgrade uses the same steps but was not run in this test).
- Same file formats and features as 0.2.2.

## Verification for this release

- Automated tests in the release build (Windows 11): 1155 passed, 0 failed, 36 skipped (the skipped tests need the maintainer's private PDFs, which are not part of the repository).
- GitHub Actions on a clean checkout ([run 39529694210](https://github.com/aungyemun/monograph-pdf/actions/runs/39529694210), Windows Server 2022): 1067 tests passed, none failed, 7 skipped because Microsoft Office, two Japanese system fonts and private PDFs are not present on the runner. The OCR tests ran there with a Tesseract engine whose 53 files are SHA-256 identical to the one shipped.
- Installer test (install, registrations, self-check, launch, uninstall, reinstall, upgrade, PDF Editor migration): 261 passed, 0 failed, 1 skipped (the elevated per-machine case).
- Upgrade from 0.2.2: settings kept, unrelated files kept, version and self-check correct, the installed program runs without the development folder — all 18 checks passed.
- Release set (file names, checksums, `SHA256SUMS.txt`, ZIP entry names, notices, versions, privacy scan of both ZIPs, OCR components): passed.

## Known limitations

- Windows 10/11 64-bit only; not code-signed.
- Physical printing on a paper printer was not tested for this release; the print path was checked by automated tests that print to a PDF file.
- Signatures are visual only (not certificate-based digital signatures).
- PDF to Word / Excel / PowerPoint is best-effort on complex layouts; Office to PDF needs Microsoft Office or LibreOffice installed.
- OCR recognizes English and Japanese only.
