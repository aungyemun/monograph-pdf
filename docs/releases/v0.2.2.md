Monograph PDF 0.2.2 — first public release. An offline PDF editor for Windows 10/11 (64-bit): view, edit, annotate, fill and design forms, organize, convert, OCR (English/Japanese), protect, redact and sign PDFs. No cloud, no uploads, no telemetry.

## New in this release

- **Bookmarks you can edit** in the Navigation panel: add (Ctrl+B), rename, point at the current page, reorder, delete — undoable and saved with the file.
- **Protect ▸ Remove Hidden Information…**: finds metadata, attached files, scripts and automatic actions, thumbnails, private application data, comments, fields, links, bookmarks and invisible (OCR) text, and saves a copy without what you choose; the copy is re-checked and the result reported.
- **Bates numbers** in Header, Footer & Page Numbers.
- **Print**: odd or even pages, reverse order, document without comments.
- **Protect with Password**: offline strength rating and a warning when both passwords are the same.
- **Edit ▸ Copy Page as Picture** (Ctrl+Alt+C).
- Page design (headers, footers, page numbers, watermarks, backgrounds) placed correctly on rotated pages, replaceable and removable; whole-page redaction and a check for redacted text left elsewhere in the file; merged files keep their bookmarks; Images to PDF leaves out photo location and camera data.
- Menus: every item has its own Alt-letter, an icon and a tooltip.

Full list: [CHANGELOG.md](https://github.com/aungyemun/monograph-pdf/blob/v0.2.2/CHANGELOG.md).

- Packaged-app smoke test, release contents check, source-archive check and branding scan: passed.
- Installer test (install, registrations, self-check, uninstall/reinstall, upgrade): 261 passed, 0 failed, 1 skipped (the elevated per-machine case, which was then checked by a real per-machine upgrade).
- Hands-on checks of the new menus and dialogs in the running app; see the changelog for what changed.

## Known limitations

- Windows 10/11 64-bit only; not code-signed.
- Signatures are visual only (not certificate-based digital signatures).
- PDF to Word / Excel / PowerPoint is best-effort on complex layouts; Office to PDF needs Microsoft Office or LibreOffice installed.
- Physical printing on a paper printer was not tested for this release (printing was checked with Microsoft Print to PDF).
