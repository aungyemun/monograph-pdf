# Monograph PDF 0.1.0 (macOS)

First **macOS** release of Monograph PDF. Versioned independently of the Windows line (Windows remains on 0.5.x).

## Download

- `MonographPDF_0.1.0_macOS.zip` — unsigned `.app` for Apple silicon (macOS 13+)

This build is **not code-signed**. On first open, use **Right-click → Open** (or allow it in System Settings ▸ Privacy & Security) if Gatekeeper blocks it.

## Highlights

- Offline PDF editing on macOS with the shared PySide6 / PyMuPDF core
- Bundled OCR (`eng` / `jpn` / `osd`) via a project-local Tesseract
- Finder reveal, Application Support / Caches paths, fcntl single-instance
- LibreOffice Office→PDF when installed under `/Applications`

## Notes

- Automatic Windows installers / Authenticode update installation are not used on macOS
- Microsoft Office COM conversion remains Windows-only
- See `docs/MACOS.md` in the source tree

## Verify

```bash
shasum -a 256 MonographPDF_0.1.0_macOS.zip
```
