Monograph PDF 0.3.0, released 2026-10-22. A feature release of the offline PDF editor for Windows 10/11 (64-bit): new editing, comment, stamp, signature, OCR, conversion, printing and compression tools, interface fixes for small screens and display scaling, and the groundwork for secure updates and private problem reports, which are built in but **switched off** in this release.

## What is new

- **Editing**: replaced text no longer overlaps the original and keeps its font, size, color and style; opacity, letter spacing, rotation and dash style in the Inspector; copy, paste, duplicate and arrange shapes and pictures.
- **Comments, stamps and signatures**: a Comments panel, squiggly underline, undo for every annotation change; a stamp library with custom text and picture stamps; drawn, typed and picture signatures placed as movable objects (visual signatures, not certificate-based).
- **Pages**: undoable page operations and a thumbnail right-click menu.
- **OCR**: recognize text in an area, extract and correct text, scanned PDF to Word; OCR on rotated pages and with non-English folder and user names fixed.
- **Conversion**: batch conversion; PDF to PowerPoint keeps mixed page sizes; PDF to Word uses one section per page size; Office files carry the PDF's title, author and dates.
- **Compress PDF**: lossless, balanced, smallest file or an exact maximum size, with an estimate, the measured result and a side-by-side preview.
- **Printing**: true black-and-white, custom scale, 2/4/6/9 pages per sheet, Save as PDF, multi-page preview.
- **Reliability**: overwriting a file is atomic; the window no longer freezes in Fit Width or Fit Page with mixed portrait and landscape pages; many layout fixes at 1366 × 768 and at 150 % display scaling.

Full list: [CHANGELOG.md](https://github.com/aungyemun/monograph-pdf/blob/v0.3.0/CHANGELOG.md).

## Feature status

| Status | Features |
| :--- | :--- |
| Included | Viewing, editing, comments, forms, organizing pages, page design, PDF to Office and images, compression, OCR in English and Japanese, password protection, redaction, removal of hidden information, printing |
| Needs another application | Office files to PDF and Office round trips need Microsoft Office or LibreOffice (tested with Microsoft 365 and LibreOffice 24.2 only) |
| Limited | PDF to Word, Excel or PowerPoint is best-effort for complex or scanned layouts; optional OCR language packs are installed only from a file you supply that matches the pinned SHA-256, and their recognition quality has not been tested; editing Japanese vertical text is not fully supported |
| Built in, switched off | Update checks and automatic upgrades (no production update-signing key yet: **Help ▸ Check for Updates…** reports "Updates not configured"); sending problem reports (**Send to Developer** sends nothing) |
| Not supported | Certificate-based digital signatures; macOS, Android and iOS |

Monograph PDF itself makes no network connections in this release. Office conversions use the locally installed Office suite, which follows its own settings.

## Compatibility

- Windows 10/11, 64-bit. Setup upgrades an existing 0.2.2 or 0.2.3 installation in place and is designed to keep settings and documents. **The upgrade from 0.2.x and the preservation of settings were not tested for this release** (the installer test was not run; see Verification).
- Files created with 0.2.x open and save as before.

## Known limitations

- Windows 10/11 64-bit only; the installer and program are not code-signed.
- Update checks, automatic upgrades and the sending of problem reports are switched off; install new versions from the Releases page.
- Signatures are visual only (not certificate-based digital signatures).
- PDF to Word / Excel / PowerPoint is best-effort on complex layouts; Office to PDF needs Microsoft Office or LibreOffice installed.
- OCR recognizes English and Japanese; other languages need an optional language pack you supply.
- Printing is raster at high resolution; **Save as PDF** keeps text.
- Setup.exe is not byte-for-byte reproducible (Inno Setup records the build time). The source archive is reproducible from the commit; the program files were reproducible between builds on the same build environment, which was not checked on another machine.
