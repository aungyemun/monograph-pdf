# Monograph PDF 0.1.1 (Linux)

First published **Linux** release, built from the unified `main` tree. Versioned independently of the
Windows line (Windows remains on 0.5.1). Linux 0.1.0 was prepared but never published; its changes
are included here, together with every shared fix and feature of Windows 0.5.1.

## Download

| File | Contents |
| :--- | :--- |
| `MonographPDF_0.1.1_Linux_x86_64.tar.gz` | Built application (`MonographPDF/`) with bundled OCR and `install.sh` |
| `MonographPDF_0.1.1_Linux_Source.tar.gz` | Source of this release (`git archive` of the tagged commit) |
| `SHA256SUMS.txt` | SHA-256 checksums of the two archives |
| `*.asc` | Detached GPG signatures of each file above |
| `MonographPDF_release_signing_key.asc` | Public GPG key used for the signatures |

The built application needs Linux x86_64 with **glibc 2.43 or newer** (for example Ubuntu 26.04),
because it was built on Ubuntu 26.04 and bundles some of its system libraries. It was tested there
on GNOME/Wayland. On older distributions, run from the source archive instead (see `LINUX.md`).

## Verify

The archives are signed with GPG key `A52B63B542BD28B43043305CA786D8E81C51772F`
(Aungyemun). Check the fingerprint through a channel other than this page before trusting it.

```bash
gpg --import MonographPDF_release_signing_key.asc
gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt
sha256sum -c --ignore-missing SHA256SUMS.txt
```

The builds are not code-signed in any other sense, and Linux has no automatic update channel.

## Install

```bash
tar -xzf MonographPDF_0.1.1_Linux_x86_64.tar.gz
bash MonographPDF/install.sh MonographPDF
```

`install.sh` installs per user into `~/.local/share/Monograph PDF`, links `~/.local/bin/MonographPDF`,
writes a desktop launcher and makes Monograph PDF the default PDF application. Remove it with
`~/.local/share/Monograph PDF/uninstall.sh` (settings are kept). The extracted folder also runs
without installing: `./MonographPDF/MonographPDF`.

## Changes

* Self-contained PyInstaller build; OCR works without a system Tesseract.
* `install.sh` now points the desktop launcher at the bundled icon.
* All shared changes since Linux 0.1.0, as listed for Windows 0.5.0 and 0.5.1 in
  [CHANGELOG.md](../../CHANGELOG.md).

See `## Linux 0.1.1 — 2026-11-04` in [CHANGELOG.md](../../CHANGELOG.md).

## Testing

* Automated suite on the release machine (offscreen Qt): 2081 tests, 2029 passed, 0 failed,
  52 skipped (Windows-only, private-fixture and environment-specific tests).
* Built binary: `--smoke-test` passed with a minimal environment (`PATH=/usr/bin:/bin`), including
  OCR, PDF to Word, protect/unlock, LibreOffice detection and the no-network check.
* Isolated `install.sh` install, launch and uninstall: passed.
* Native start on GNOME Wayland: passed.

## Known limitations

* Interactive printing and physical printers: **NOT VERIFIED**.
* Distributions other than Ubuntu 26.04: **NOT VERIFIED**.
* Microsoft Office COM conversion is Windows-only; Office to PDF uses a locally installed LibreOffice.
* Certificate-based PDF digital signatures are not supported (visual signatures only).
