Monograph PDF 0.5.0, released 2026-10-28. A feature release of the offline PDF editor for Windows 10/11 (64-bit) that also corrects a security defect: several commands wrote copies of password-protected PDFs without their protection. New are several PDFs open at once in tabs, a scroll button and automatic scrolling, a new colour picker, pictures placed behind the text, consistent handling of protected, digitally signed and watermarked PDFs, and 45 optional OCR languages. It also contains everything prepared for 0.4.1 and 0.4.2, which were not published: signed update checks, the font and Japanese-text fixes, the simpler Compress PDF dialog, and the editing improvements.

## Security updates

- **Update checks are switched on** (first published version with them). **Help ▸ Check for Updates…** contacts only this project's GitHub Releases page, accepts only update information signed with the Monograph PDF update-signing key (Ed25519, key id `27c3b3b23b949c40`), and downloads or installs nothing until you click **Update Now**; the downloaded installer must match the SHA-256 in the signed information before it is run. Automatic checks are optional and off by default. **0.4.0 and earlier cannot update themselves**: install 0.5.0 once with Setup; later versions can then be found with Check for Updates. Only Windows releases are considered: the newest Windows release that carries a signed update manifest, never a macOS or Linux release shown as GitHub's "Latest".
- **Copies of password-protected PDFs keep their protection.** Save a Copy, Copy with Metadata, Remove Document Information, Flattened PDF, Watermark, Header & Footer, Background, removing page design, Extract Pages, Redact, Compress and Make Searchable (OCR) wrote some of their results **without the password protection** of the original (and some lost bookmarks and attachments). Every PDF written from a protected PDF now keeps the same open password, permissions password, permissions and encryption.
- **The permissions of a protected PDF are honoured.** With the open password only, actions the author did not allow — converting or copying the content, printing, saving changes, assembling pages — ask for the permissions (owner) password. **Remove Protection** needs the permissions password when the PDF restricts anything. Batch Convert skips such files with a message.
- **Digitally signed PDFs**: Save As without changes copies the file byte for byte, so its signatures stay valid; Save without changes no longer rewrites the file; Save with changes over a signed PDF asks first. Empty signature fields no longer cause signature warnings.
- **OCR language downloads** happen only when you click **Download and Install**, over HTTPS with certificate checks to `github.com` / `raw.githubusercontent.com` only; a file is installed only if its size and SHA-256 match the value shipped with Monograph PDF. The [privacy policy](https://github.com/aungyemun/monograph-pdf/blob/v0.5.0/docs/PRIVACY_POLICY.md) describes it.

## Defects corrected

- **Forms**: check boxes whose "on" name is not plain ASCII (many Japanese forms) were saved ticked on screen but unticked in the value and showed unticked after reopening; text fields stay fillable after Save; a font defined by the form (for example Times New Roman) is no longer replaced by Helvetica; long entries in multi-line fields with Auto font size are shrunk to fit instead of being cut off.
- **Japanese text** in a chosen Japanese font (MS Gothic, MS Mincho, Meiryo …) is shown, laid out and saved in that font (the screen used Yu Gothic UI). **Edit Text** on existing text keeps the original font, and a longer replacement no longer overlaps the next word.
- **Freezes of several seconds** while scrolling long documents; **Find Next / Previous** set the current page one match late; dragging one of **several selected objects** moved only that one; a drag on empty paper now also selects shapes and pictures; a resize handle caught off-centre no longer makes the edge jump.

- **Crash when choosing a font while editing text**, and the font list closing on the first click (prepared for 0.4.1).
- **Fonts installed as collections (.ttc / .otc)** such as MS Mincho, MS Gothic, Meiryo or Yu Gothic were replaced by a built-in font when saving; they are now embedded (only the characters used), and Japanese text keeps full-width spacing (prepared for 0.4.1).
- A picture stretched with **Lock aspect ratio** off was saved letterboxed instead of stretched as on screen.
- From 0.4.2 (not published): a text box just placed could not be resized; a crash while scrolling the font list after typing in a text box; selected words in a text box lost their selection when a font was chosen; filled forms looked empty in Adobe Acrobat (XFA forms); sticky notes moved late and showed their text on hover; the eraser was slow on pages with many marks. Details in the changelog.

## Improvements

- **Several PDFs open at once**, each in its own tab (search, page, zoom and unsaved changes kept per tab; opening a PDF that is already open switches to its tab). **Arrow keys** move selected shapes, text boxes, form fields and comments.
- **Scroll button**: press the mouse wheel button on a page and move the pointer above or below the marker; the pages scroll that way, faster the further away. **View ▸ Automatic Scrolling** (Ctrl+Shift+L) scrolls at a steady speed (↓ / ↑ change it, Esc stops).
- **New colour picker** for every colour: colour field and hue strip, current and new colour side by side, Hex or a colour name, R G B, standard and recent colours, **Pick from Screen**, and the contrast on white paper for text.
- **Pictures behind text**: **Behind Text** lets the page's text and lines show through a placed picture, also on scanned pages (Image toolbar, **Edit ▸ Selected Image**, Properties panel).
- **Protected, signed and watermarked PDFs**: PDF to Word and PowerPoint can leave out the watermark, header/footer and background added with Monograph PDF; **Protect ▸ View Permissions** explains how the PDF is handled. Rules: [Protected, signed and watermarked PDFs](https://github.com/aungyemun/monograph-pdf/blob/v0.5.0/docs/PROTECTED_SIGNED_WATERMARKED_PDFS.md).
- **OCR languages**: 45 optional languages (35 new, among them Arabic, Burmese, Dutch, Greek, Hindi, Italian, Polish, Portuguese, Russian, Thai, Turkish, Ukrainian and Vietnamese); **OCR ▸ OCR Languages** with a searchable list, **Download and Install**, **Install from File…** for several files, and language files found in the Downloads folder. An installed language can be used at once.
- **Compress PDF** asks one question with five explained answers and never changes text or fonts (prepared for 0.4.1).
- From 0.4.2 (not published): word formats inside text boxes, Find for scientific notation (Greek letters, units, exponents), shape line thickness and arrow ends, form field background and border, colours matched to a wide-gamut monitor profile, a redesigned sticky-note card, zoom around the pointer, and Protect with Password options for document information and watermarks.

Full list: [CHANGELOG.md](https://github.com/aungyemun/monograph-pdf/blob/v0.5.0/CHANGELOG.md).

## Compatibility

- Windows 10/11, 64-bit. Setup upgrades an existing 0.4.0, 0.3.0 or 0.2.x installation in place and is designed to keep settings and documents (settings migrations are covered by automated tests).
- Files created with earlier versions open and save as before. Behaviour change: a protected PDF opened with its open password only can no longer be changed, converted or printed beyond its permissions without the permissions password.

## Known limitations

- Windows 10/11 64-bit only; the installer and program are not code-signed.
- Signatures are visual only (not certificate-based digital signatures); exported files are never digitally signed.
- The sending of problem reports is switched off; a problem report can be copied and posted on the issues page by hand.
- Updates are signed with one production key (`27c3b3b23b949c40`). A separately protected recovery key, trusted in addition to it so that updates can continue if the primary key is ever lost, may be introduced in a future version ([Secure updates](https://github.com/aungyemun/monograph-pdf/blob/v0.5.0/docs/SECURE_UPDATES.md)); 0.5.0 does not include one.
- The recognition quality of the optional OCR languages has not been tested by the project beyond German and Burmese sample text.
- Edit Text replaces a run of text on its line; following runs in another style are not moved (a much longer replacement can reach them).
- Starting Monograph PDF with several files at once (for example from Explorer) opens the first; open the others with **File ▸ Open**.
- Reading back in Adobe Acrobat was not automated for this release (checks used MuPDF).
