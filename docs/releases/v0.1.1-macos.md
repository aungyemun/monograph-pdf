# Monograph PDF 0.1.1 (macOS)

macOS maintenance and parity release, built from the unified `main` tree. Versioned independently
of the Windows (0.5.1) and Linux (0.1.1) lines, and includes every shared fix of Windows 0.5.1.

## Download

| File | Contents |
| :--- | :--- |
| `MonographPDF_0.1.1_macOS.pkg` | Guided installer → `/Applications` (upgrades in place, refuses downgrades) |
| `MonographPDF_0.1.1_macOS.dmg` | Disk image: drag Monograph PDF to Applications |
| `MonographPDF_0.1.1_macOS.zip` | The app as a `ditto` archive |
| `*.corresponding-source.tar.gz` | Corresponding source of the copyleft OCR libraries (lzo, libiconv) |
| `SHA256SUMS.txt` | SHA-256 checksums of every file above |

Apple silicon, macOS 13 or later.

**Signing:** the app is **ad-hoc signed and not notarized** (no Apple Developer ID). Gatekeeper
blocks it on first open: Control-click the app → **Open**, or allow it in System Settings ▸
Privacy & Security.

## Highlights

- **OCR works in the installed app** (0.1.0's bundle linked OCR one folder too shallow). Tesseract
  5.5.3 and its libraries ship unmodified from pinned conda-forge builds, with licenses, provenance
  and corresponding source.
- Opening PDFs from Finder, Open With and the Dock; Make Default PDF App through LaunchServices.
- Mac keys: Control+Tab / ⌘⇧] / ⌘⇧[ for document tabs, Control+⌘F for full screen.
- Guided `.pkg`, designed `.dmg` and `.zip`, each checked by the release verifier.
- Shared fixes from Windows 0.5.1: Save As onto a file open in another tab, safe failed saves,
  plain-language save errors, stale text under edited form fields, cleared form fields saved.
- Check for Updates on macOS points to GitHub Releases; it never offers the Windows line.

## Verify

```bash
shasum -a 256 -c SHA256SUMS.txt
```
