## Version accuracy and maintenance

**The platform-specific examples above represent the latest published releases verified on November 4, 2026.** After a new release is published, update that platform's example (version, release tag, and publication year if needed). Do **not** replace an older version in a paper that actually used that older release.

The universal [CITATION.cff](../CITATION.cff) supplies the project-wide citation metadata and intentionally omits a platform-specific version. GitHub's built-in **Cite this repository** feature therefore provides the universal reference; these four copyable blocks provide the exact platform options. Before citing a newer release, always check the [releases page](https://github.com/aungyemun/monograph-pdf/releases).

For reproducibility, also record the application version, operating system, and release tag (or commit for unreleased source builds) in your Methods section. PDF processing for routine manuscript formatting may not always require a formal software citation.

## Software abstract

Monograph PDF is a free and open-source desktop application for viewing, editing, annotating, organizing, converting, and securing PDF documents across Windows, macOS, and Linux. It provides document editing, interactive forms, page management, conversion, compression, optical character recognition (OCR), redaction, password protection, and visual signatures. It emphasizes local document processing, offline use, and user privacy without requiring cloud services or user registration. Optional functions may require locally installed software or explicitly initiated downloads. Monograph PDF is licensed under AGPL-3.0-or-later. Visual signatures are not certificate-based digital signatures.
