Before you install

  • Requires macOS {{MIN_MACOS}} (Ventura) or later on a Mac with Apple silicon.
  • Installs to Applications. You may be asked for an administrator password.
  • Quit Monograph PDF before upgrading.

How to install

  1. Click Continue and read the license.
  2. Click Install. The installer shows the space required.
  3. When it finishes, open Monograph PDF from Applications, Launchpad or Spotlight.

Your data

Settings and recent files live in your user Library and are never changed by installing, upgrading or removing the app. To remove Monograph PDF, drag it from Applications to the Trash.
